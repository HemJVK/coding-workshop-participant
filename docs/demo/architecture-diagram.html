ACME Platform Architecture

Modern architecture view with semantic shape language and explicit lanes for user experience, edge, gateway, service domains, analytics decisions, persistence, and deployment controls.

Circle: Actor Cloud: Edge Layer Hexagon: Core Stack Diamond: Decision Point Cylinder: Data Store Rounded Card: Domain Service

Flow Narrative

  • User enters through React frontend with JWT-aware API client and route guards.
  • CloudFront handles edge routing, SPA rewriting, and API header policy.
  • FastAPI gateway validates request context and dispatches to isolated service modules.
  • Service domains enforce RBAC and manager ownership checks before data operations.
  • Analytics service consolidates domain data into strategic insights endpoints.
  • PostgreSQL persists operational records and supports aggregations for analytics.
